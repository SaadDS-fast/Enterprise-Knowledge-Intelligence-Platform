# Operator Controls

Authoritative backend controls:

- `AGENTIC_RAG_ENABLED`
- `AGENT_RESEARCH_ENABLED`
- `AGENT_WEB_SEARCH_ENABLED`
- `AGENT_EXTERNAL_APIS_ENABLED`
- `AGENT_MAX_STEPS`
- `AGENT_MAX_TOOL_CALLS`
- `EVIDENCE_MAX_ITEMS`
- `AGENT_RESEARCH_MAX_SOURCES`
- `AGENT_RESEARCH_MAX_REPORT_WORDS`
- `AGENT_RESEARCH_MAX_CONCURRENT_PER_USER`
- `AGENT_RESEARCH_MAX_CONCURRENT_PER_WORKSPACE`
- `AGENT_RESEARCH_MAX_QUEUED_JOBS`
- `MAX_REQUEST_BODY_BYTES`
- `MAX_UPLOAD_BYTES`
- `RATE_LIMIT_REQUESTS`
- `RATE_LIMIT_WINDOW_SECONDS`

Frontend `NEXT_PUBLIC_*` flags are visibility controls only and must not be treated as security
controls.

Typed safe errors include `RATE_LIMITED`, `CONCURRENCY_LIMIT_REACHED`, `REQUEST_TOO_LARGE`,
`BUDGET_EXCEEDED`, `PROVIDER_UNAVAILABLE`, `TEMPORARY_FAILURE`, and feature-disabled responses.
